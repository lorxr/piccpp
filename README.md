# 🏥 Sistema de Triagem Hospitalar

Projeto Integrador desenvolvido pelos cursos de **Ciência da Computação** e **Publicidade e Propaganda**, com o objetivo de criar um sistema de apoio à triagem hospitalar.

## 📌 Sobre o Projeto

O sistema permite cadastrar pacientes, registrar informações iniciais da triagem e utilizar Inteligência Artificial para auxiliar na análise dos sintomas informados.

A IA pode sugerir uma possível classificação de risco, um pré-diagnóstico e uma descrição clínica inicial para apoiar o atendimento.

> Este projeto tem finalidade acadêmica e não substitui a avaliação de um profissional da saúde.

## 🚀 Funcionalidades

- Cadastro de pacientes;
- Registro de triagem;
- Coleta de sintomas e sinais vitais;
- Análise com apoio de IA;
- Classificação de risco;
- Salvamento das informações no banco de dados;
- Interface web simples e organizada.

## 🛠️ Tecnologias Utilizadas

- Python
- Flask
- HTML
- CSS
- JavaScript
- Banco de dados
- Inteligência Artificial
